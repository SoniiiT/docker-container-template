# Project knowledge

`.ai-context/` contains compact, evidence-based generated context plus curated lifecycle guidance. Source code and explicit project rules are authoritative over these summaries.

- `decisions/` records confirmed architecture decisions; none were found during initialization.
- `business-rules/` records confirmed domain invariants; none were found because this is a template catalog.
- `feature-guides/` records safe change guidance for template families.
- `removal-guides/` records data, network, and compatibility concerns when deleting a template.
- `risks/` records observed security, maintenance, and operational risks.

Observed facts are labeled by evidence from repository files. Inferences are labeled as such. Human-authored knowledge must be preserved during refreshes.
